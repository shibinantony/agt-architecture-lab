# Contributing

Corrections, issues and pull requests are welcome. Original code and documentation use the [MIT License](LICENSE.md). Submit changes only when you have the right to contribute them under that license; retain existing copyright and attribution notices.

Useful feedback includes a reproducible synthetic case, expected and observed behavior, platform/interpreter versions, relevant policy format, and a primary source for current vendor claims.

Use [AGT's official repository](https://github.com/microsoft/agent-governance-toolkit) for upstream bugs. This companion has an original emulator and a separate source-pinned AGT example; identify which one your report concerns.

Before proposing changes, run the tests and repository validation described in [README](README.md). Keep secrets, real environment data, private conversations and employer/client material out of changes. State exactly which client, transport, runtime and environment were tested; do not turn a source reference into an execution claim.

For a dependency or adapted third-party contribution, identify the upstream version, license and required notices in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). Discuss changes to tool authority, identity, cost accounting or external side effects before implementing them. Keep feedback respectful and specific.
